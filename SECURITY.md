# Security Policy

The Automated Actions project takes security issues seriously, especially because this app can execute automation logic across Frappe documents and scheduled jobs.

## Reporting a Vulnerability

Please do not open a public GitHub issue for suspected security vulnerabilities.

Instead, report the issue privately to:

- Email: ar.frappe.dev@gmail.com

Please include:

- A clear description of the issue
- Steps to reproduce it
- Affected versions or commit range, if known
- Any proof-of-concept, logs, or screenshots needed to validate the report
- Your assessment of potential impact

## Response Process

- We will acknowledge receipt as soon as reasonably possible
- We will investigate and validate the report
- We may request more details if reproduction is unclear
- We will coordinate disclosure timing when a fix is required

## Supported Versions

Security fixes are generally targeted at the latest maintained branch for this repository.

If you are running a fork or older custom deployment, please confirm whether the issue is reproducible against the latest develop branch before reporting.
